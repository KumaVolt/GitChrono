> [!WARNING]
> **GitChrono is in alpha. Use at your own risk.** It runs real git commands on your repositories, so keep a pushed remote or a backup of anything you can't afford to lose.

## What's new in 0.5.0

**Start a repository from GitChrono**
- **Clone…** on the Home tab and in the command palette: paste a URL, pick a folder, and follow git's progress as it downloads; the new repository opens in a tab when it's done
- **New repository…** runs `git init` in a folder you pick (or create), on `main` unless your git config names another branch
- A brand-new repository with no commits yet works throughout, including unstaging files before the first commit

**Home tab**
- Home is always the first tab and can't be closed; repositories you open from it get their own tab instead of replacing it, and **+** / ⌘T go back to it
- Remove a repository from Recent or from a project folder's list with the **×** that appears on hover. Nothing on disk changes, and a folder's hidden repositories can be shown and restored again
- Removing a project folder now asks first

**Toolbar**
- Every button has an icon above its label, and disabled buttons dim their icon too

**Committing**
- Clicking anywhere in the commit title or description box, corners included, lets you type straight away (before, a click near the edge lit up the border but keystrokes went nowhere)

**Profile pictures**
- Authors' pictures from Gravatar are now on by default, also for existing installs. Gravatar receives a hash of each author's email; turn it off in Settings → Profile pictures
- The Profile pictures switch in Settings no longer sticks out of its card

## Install

| Platform | File |
|---|---|
| macOS (Apple Silicon and Intel) | `GitChrono-0.5.0-macos-universal.dmg` |
| Windows 64-bit | `GitChrono-0.5.0-windows-x86_64.zip` (Git included) |
| Linux x86_64 / ARM64 | `GitChrono-0.5.0-linux-*.tar.gz` |

Already on 0.3.0 or newer? GitChrono offers this update itself. Step-by-step instructions are on [gitchrono.com/download](https://gitchrono.com/download/).

Requires `git` 2.40 or newer (included on Windows).
