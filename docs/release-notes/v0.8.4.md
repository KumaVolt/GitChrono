> [!WARNING]
> **GitChrono is in alpha. Use at your own risk.** It runs real git commands on your repositories, so keep a pushed remote or a backup of anything you can't afford to lose.

## What's new in 0.8.4

**Git LFS**
- Repositories that use Git LFS get an **LFS** button next to Terminal. It shows when LFS still needs setting up or files still need downloading, and its menu sets LFS up for that repository, downloads missing files and frees up space
- A large file stored in LFS shows its size in the diff (for example "2.4 MB → 3.1 MB") instead of the placeholder text git keeps for it
- Right-click a file to track it, or every file with its extension, with Git LFS
- Windows: Git LFS is now bundled with the included Git

**Readable errors**
- When git refuses something, GitChrono now says what happened in plain language. The raw git output is still there behind **Details**
- Problems with a fix show it as a blue bar with a button: for example, a pull blocked by your local changes offers **Stash and pull**, and a branch that can't be fast-forwarded offers **Pull with merge**

**Changes panel**
- The Unstaged and Staged sections fold away, and you can drag the line between them to resize them. GitChrono remembers the split per repository; double-click the line to reset it
- **Stash** stashes straight away with an automatic name ("WIP on main: …"). To write your own message, use "Stash changes with message…" in the command palette

**Home**
- Fetch, pull, open and remove are now icon buttons, on each group and when you hover a repository

## Install

| Platform | File |
|---|---|
| macOS (Apple Silicon and Intel) | `GitChrono-0.8.4-macos-universal.dmg` |
| Windows 64-bit | `GitChrono-0.8.4-windows-x86_64-setup.exe`, or the portable `GitChrono-0.8.4-windows-x86_64.zip` (Git and Git LFS included in both) |
| Linux x86_64 / ARM64 | `GitChrono-0.8.4-linux-*.tar.gz` |

Already on 0.3.0 or newer? GitChrono offers this update itself. Step-by-step instructions are on [gitchrono.com/download](https://gitchrono.com/download/).

Requires `git` 2.40 or newer (included on Windows). Git LFS features need `git-lfs` installed (included on Windows).
