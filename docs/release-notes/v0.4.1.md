> [!WARNING]
> **GitChrono is in alpha. Use at your own risk.** It runs real git commands on your repositories, so keep a pushed remote or a backup of anything you can't afford to lose.

## What's new in 0.4.1

**Pushing when the remote moved on**
- If your branch is behind, or someone pushed while you were working, GitChrono explains it and offers **Pull and push** instead of showing git's error
- Pull now follows your Pull setting (merge or rebase) from Settings

**Committing**
- After a commit, the file you had open closes along with its selection
- If a commit fails, your message stays in the box instead of being cleared

**Syntax colors**
- Edited PHP files are colored again (changes in the middle of a file showed as plain text)
- Many more languages: TypeScript, TSX, JSX, Vue, Svelte, SCSS, TOML, Kotlin, Swift, Dart, Dockerfile and more

**Sidebar and graph**
- Local, Remote, Tags, Worktrees, Submodules, Pull requests and Stashes collapse with a click, remembered per repository
- Clicking the selected commit again closes its details

## Install

| Platform | File |
|---|---|
