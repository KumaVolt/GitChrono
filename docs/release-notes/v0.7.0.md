> [!WARNING]
> **GitChrono is in alpha. Use at your own risk.** It runs real git commands on your repositories, so keep a pushed remote or a backup of anything you can't afford to lose.

## What's new in 0.7.0

**A conflict editor that fills the window**
- Conflicts now open across the whole window: ours and theirs side by side, aligned row by row, with line numbers and syntax colors, and the merged **Output** live below
- Tick a side for each conflict. Tick both to keep both, in the order you ticked them. The checkbox on a pane's header picks that side for every conflict
- **conflict 1 of N** with ▲ ▼ jumps both panes between conflicts, and a conflict you haven't decided shows up in Output, so nothing gets missed
- Long lines scroll sideways without losing your place
- Saving a file opens the next conflicted one

**Fetch all and Pull all**
- Every group on the Home tab has **Fetch all** and **Pull all**, for the repositories it lists. The ▾ next to Pull all picks how it pulls, shared with the toolbar
- Each row shows how it went, and a line on top sums it up
- Repositories with no remote, no upstream, a detached HEAD or an operation in progress are skipped, and say why
- A pull that hits conflicts is undone and reported, rather than leaving a half-finished merge in a repository you aren't looking at

**Much more when you right-click**
- Branch and `HEAD` labels now offer their commit's actions too: reset, revert, cherry-pick, create tag, edit message, copy SHA
- **Fast-forward** a branch that's behind without checking it out, and **merge the current branch into the one you clicked**, next to merging the other way
- **Interactive rebase** onto a branch, local or remote
- **Drop commit** and **Move commit up / down**, which ask first when a remote already has the commits, since the branch will need a force push
- **Set upstream…**, **Force delete** for a branch with unmerged commits, **Solo** on the checked-out branch, and **Push and start a pull request** (with `gh`)
- Right-click selected commits to cherry-pick, revert or rebase them, or to copy their SHAs
- Menus use the window's height and scroll only when it's too short

**The graph**
- The WIP row's line now joins HEAD, even with other branches' commits between them
- The WIP row shows what changed, like `✎2 +2 −1`, counting each file once
- Histories with a single line of commits draw that line again; they showed only dots
- Branch labels in the graph can be dragged onto each other, or onto the sidebar, to merge or rebase

**AI**
- New in Settings: **Write commit messages automatically**. Once every change is staged and the message is empty, AI writes the summary and description, once for those files. It's off by default, since each one is a request to your provider, and it never replaces anything you've typed

**Fixed**
- The menu of the checked-out branch was all in bold
- A non-ASCII branch name could crash an interactive rebase that hit merge commits

## Install

| Platform | File |
|---|---|
| macOS (Apple Silicon and Intel) | `GitChrono-0.7.0-macos-universal.dmg` |
| Windows 64-bit | `GitChrono-0.7.0-windows-x86_64.zip` (Git included) |
| Linux x86_64 / ARM64 | `GitChrono-0.7.0-linux-*.tar.gz` |

Already on 0.3.0 or newer? GitChrono offers this update itself. Step-by-step instructions are on [gitchrono.com/download](https://gitchrono.com/download/).

Requires `git` 2.40 or newer (included on Windows).
