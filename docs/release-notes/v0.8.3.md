> [!WARNING]
> **GitChrono is in alpha. Use at your own risk.** It runs real git commands on your repositories, so keep a pushed remote or a backup of anything you can't afford to lose.

## What's new in 0.8.3

**Windows**
- No more console window next to GitChrono, and none flashing up when it runs ssh, ssh-keygen or the GitHub CLI
- A proper installer: `GitChrono-0.8.3-windows-x86_64-setup.exe` installs for your account only (no admin prompt), adds GitChrono to the Start menu and comes with an uninstaller. The download page now offers it first
- The portable `.zip` is still there for anyone who'd rather not install, and it's what in-app updates download

## Install

| Platform | File |
|---|---|
| macOS (Apple Silicon and Intel) | `GitChrono-0.8.3-macos-universal.dmg` |
| Windows 64-bit | `GitChrono-0.8.3-windows-x86_64-setup.exe`, or the portable `GitChrono-0.8.3-windows-x86_64.zip` (Git included in both) |
| Linux x86_64 / ARM64 | `GitChrono-0.8.3-linux-*.tar.gz` |

Already on 0.3.0 or newer? GitChrono offers this update itself. Step-by-step instructions are on [gitchrono.com/download](https://gitchrono.com/download/).

Requires `git` 2.40 or newer (included on Windows).
