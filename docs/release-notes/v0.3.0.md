> [!WARNING]
> **GitChrono is in alpha. Use at your own risk.** It runs real git commands on your repositories, so keep a pushed remote or a backup of anything you can't afford to lose.

## What's new in 0.3.0

**Updates itself**
- GitChrono checks GitHub for new versions, downloads the right file for your computer, verifies it against the release checksums and offers a restart
- A footer with the version, update status and About & credits (contributors and the projects GitChrono is built on)
- This is the first version with updates built in, so it's the last one you download by hand

**A graph that reads like GitKraken's**
- Commits in date order, with merges and branch lines drawn as clean rounded elbows
- Much narrower graphs on big repositories, and a graph column you can drag narrower, down to one dot per commit
- One branch label per row with a "+N" count; hover to see them all, double-click one to switch to it
- Checking out a remote branch you already have locally switches to it and brings it up to date

**Commit details**
- The message in a scrolling card with readable paragraphs, exact dates, clickable parents and a click-to-copy commit ID
- Co-authors listed under the author, with the logos of AI assistants like Claude, ChatGPT, Gemini, Copilot and Grok
- "Explain commit": an AI summary of what a commit does (with your own key)
- An added / modified / deleted summary, and a Path / Tree switch with folders you can collapse

**Staging**
- Select several files (⌘/Shift-click) to stage, unstage or discard them together
- Folder view, with a Stage button per folder

**Settings (⌘,)**
- Your git name, email, default branch, pull mode and commit signing, for all repositories or just one; empty fields show what git uses anyway
- Your SSH keys: copy a public key, use one for signing, create a new one, or test GitHub and GitLab
- Optional profile pictures from Gravatar (off by default)

**Everything else**
- A new app icon
- Collapsible project folders on the new-tab page
- Stash and Pop side by side in the toolbar, Terminal last

## Install

| Platform | File |
|---|---|
| macOS (Apple Silicon and Intel) | `GitChrono-0.3.0-macos-universal.dmg` |
| Windows 64-bit | `GitChrono-0.3.0-windows-x86_64.zip` |
| Linux x86_64 / ARM64 | `GitChrono-0.3.0-linux-*.tar.gz` |

Step-by-step instructions are on [gitchrono.com/download](https://gitchrono.com/download/). The builds aren't signed by Apple or Microsoft yet, so the first launch asks you to confirm once.

Requires `git` 2.40 or newer on your `PATH`.
