> [!WARNING]
> **GitChrono is in alpha. Use at your own risk.** It runs real git commands on your repositories, so keep a pushed remote or a backup of anything you can't afford to lose.

## What's new in 0.8.1

**Updates show up sooner**
- GitChrono now checks for updates every hour while it's open, instead of every six hours
- The hour goes by the clock, so a check that came due while your Mac was asleep runs within a minute of waking. Before, sleep paused the countdown, and a new version could go unnoticed for days unless you pressed **Check for updates**
- Checks that fail in the background (offline, for example) stay quiet; **Check for updates** in About & credits still tells you what went wrong
- This takes effect from this version on: 0.8.0 still checks the old way, so it may take a while to offer you 0.8.1

**Ignore changed files too**
- **Ignore ▸** is now on changed and staged files, not just new ones. Git keeps tracking a file it already tracks even once it's in `.gitignore`, so GitChrono says so after ignoring one
- **Ignore and stop tracking…** also takes the file out of the repository while keeping it on your disk. It asks first: your next commit removes the file from the repository, and anyone who pulls that commit has it deleted from their copy

|---|---|
| macOS (Apple Silicon and Intel) | `GitChrono-0.8.1-macos-universal.dmg` |
| Windows 64-bit | `GitChrono-0.8.1-windows-x86_64.zip` (Git included) |
| Linux x86_64 / ARM64 | `GitChrono-0.8.1-linux-*.tar.gz` |

Already on 0.3.0 or newer? GitChrono offers this update itself. Step-by-step instructions are on [gitchrono.com/download](https://gitchrono.com/download/).

Requires `git` 2.40 or newer (included on Windows).
