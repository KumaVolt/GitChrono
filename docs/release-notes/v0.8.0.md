> [!WARNING]
> **GitChrono is in alpha. Use at your own risk.** It runs real git commands on your repositories, so keep a pushed remote or a backup of anything you can't afford to lose.

## What's new in 0.8.0

**Native right-click menus**
- Right-click menus are now the system's own: real macOS menus, and Windows menus on Windows. They look and behave like every other app's, including keyboard navigation, and they can reach past the edge of the window
- This covers every right-click menu: commits, branches, tags, stashes, files, tabs, worktrees, submodules and pull requests. Linux keeps the drawn menus

**More for a single file**
- **Ignore ▸** for an untracked file: just that file, every file with its extension, or everything in its folder. The line goes into the repository's `.gitignore`, once
- **Stash file** sets just that file aside, untracked files included, in a stash named after it
- **Open in default program** and **Show in Finder** (Show in Explorer on Windows)
- **Copy full path**, next to Copy path
- **Create patch from file changes…** saves the file's staged or unstaged changes as a patch anyone can `git apply`
- With several files picked: **Stash N files** and **Create patch from N files…**

**Find a file in long change lists**
- A **Filter files…** box above the changes narrows the unstaged and staged lists as you type; several words must all appear in the path
- While filtering, the lists show "N of M", and the buttons become **Stage shown** and **Unstage shown**, so they act on what you see

**Fixed**
- Two interactive rebases running at the same time with the same base could break each other

## Install

| Platform | File |
|---|---|
| macOS (Apple Silicon and Intel) | `GitChrono-0.8.0-macos-universal.dmg` |
| Windows 64-bit | `GitChrono-0.8.0-windows-x86_64.zip` (Git included) |
| Linux x86_64 / ARM64 | `GitChrono-0.8.0-linux-*.tar.gz` |

Already on 0.3.0 or newer? GitChrono offers this update itself. Step-by-step instructions are on [gitchrono.com/download](https://gitchrono.com/download/).

Requires `git` 2.40 or newer (included on Windows).
