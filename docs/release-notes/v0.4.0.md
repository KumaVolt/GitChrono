> [!WARNING]
> **GitChrono is in alpha. Use at your own risk.** It runs real git commands on your repositories, so keep a pushed remote or a backup of anything you can't afford to lose.

## What's new in 0.4.0

**Works on computers without Git**
- The Windows download now includes Git (MinGit from Git for Windows). If you already have Git installed, GitChrono keeps using yours
- On macOS and Linux, GitChrono shows how to install Git instead of empty tabs: one click for Apple's Command Line Tools, or the right install command for your Linux distribution. "Check again" brings your tabs back
- GitChrono also finds Git installed with Homebrew when opened from Finder
- About shows which Git is in use

**Repository overview on the new-tab page**
- Every repository shows its owner, current branch, commits ahead ↑ and behind ↓ its remote, and how many files are modified, new, deleted or in conflict
- Repositories that can't be read anymore get a warning

**Fixes**
- More reliable macOS release builds

## Install

| Platform | File |
|---|---|
| macOS (Apple Silicon and Intel) | `GitChrono-0.4.0-macos-universal.dmg` |
| Windows 64-bit | `GitChrono-0.4.0-windows-x86_64.zip` (Git included) |
| Linux x86_64 / ARM64 | `GitChrono-0.4.0-linux-*.tar.gz` |

Already on 0.3.0? GitChrono offers this update itself. Step-by-step instructions are on [gitchrono.com/download](https://gitchrono.com/download/).

Requires `git` 2.40 or newer (included on Windows).
