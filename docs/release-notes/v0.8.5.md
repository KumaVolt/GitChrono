> [!WARNING]
> **GitChrono is in alpha. Use at your own risk.** It runs real git commands on your repositories, so keep a pushed remote or a backup of anything you can't afford to lose.

## What's new in 0.8.5

**Fewer keychain prompts on macOS**
- GitChrono no longer reads your AI provider's API key from the keychain when it starts, when you open AI settings, or when you click a provider. It reads the key only when an AI request runs, once per launch
- Click **Always Allow** on that prompt and it stays quiet until the next GitChrono update

## Install

| Platform | File |
|---|---|
| macOS (Apple Silicon and Intel) | `GitChrono-0.8.5-macos-universal.dmg` |
| Windows 64-bit | `GitChrono-0.8.5-windows-x86_64-setup.exe`, or the portable `GitChrono-0.8.5-windows-x86_64.zip` (Git and Git LFS included in both) |
| Linux x86_64 / ARM64 | `GitChrono-0.8.5-linux-*.tar.gz` |

Already on 0.3.0 or newer? GitChrono offers this update itself. Step-by-step instructions are on [gitchrono.com/download](https://gitchrono.com/download/).

Requires `git` 2.40 or newer (included on Windows). Git LFS features need `git-lfs` installed (included on Windows).
