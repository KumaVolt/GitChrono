Install

Up and running in a minute.

The builds aren't signed by Apple or Microsoft yet, so the first launch asks you to confirm once.

macOS

  1. Open the .dmg and drag GitChrono into Applications.
  2. Open GitChrono. If macOS says it can't check the developer, go to System Settings → Privacy & Security and click Open Anyway.
  3. On macOS 14 and earlier you can instead Control-click the app and choose Open.

One build for Apple Silicon and Intel Macs, macOS 11 or newer.

Windows

  1. Extract the .zip, ideally to %LOCALAPPDATA%\Programs\GitChrono so updates can replace it.
  2. Run gitchrono.exe. If SmartScreen appears, click More info → Run anyway.
  3. Right-click it in the taskbar and pin it to keep it handy.

Windows 10 or 11, 64-bit. Git is included: GitChrono uses your own Git for Windows if you have it, and its bundled copy otherwise.

Linux

  1. Extract the archive and install the app for your user:
tar -xzf GitChrono-*-linux-*.tar.gz
cd GitChrono-*-linux-*/
install -Dm755 gitchrono ~/.local/bin/gitchrono
install -Dm644 gitchrono.desktop \
  ~/.local/share/applications/gitchrono.desktop
install -Dm644 gitchrono.png \
  ~/.local/share/icons/hicolor/512x512/apps/gitchrono.png

Then start it from your app menu or run gitchrono. Needs a desktop with Vulkan graphics drivers (standard on current distributions).

Updates and checksums

Staying up to date.

Newer versions of GitChrono update themselves: the app checks GitHub for new releases, downloads the right file for your computer, verifies it, and asks you to restart. You can turn automatic checks off in Settings.

Every release also comes with a SHA256SUMS.txt file if you want to check a download yourself:

# macOS and Linux, in the folder with the download and SHA256SUMS.txt
shasum -a 256 -c SHA256SUMS.txt --ignore-missing

# Windows (PowerShell): compare with the line in SHA256SUMS.txt
Get-FileHash .\GitChrono-*-windows-x86_64.zip -Algorithm SHA256

See what changed in each version, or browse every build on GitHub Releases. Prefer to build it yourself? The source is on GitHub: cargo run -p gitchrono-app.
