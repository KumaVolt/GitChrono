GitChrono is in alpha. Use at your own risk. It runs real git commands on your repositories, so keep a pushed remote or a backup of anything you can't afford to lose.

What's new in 0.2.0

Work across repositories

  • A tab per repository, restored on launch (⌘T, ⌘W, Ctrl+Tab)
  • Add a parent folder and every repository inside it shows up on the new-tab page
  • Worktrees: create one from any branch, open it in its own tab, remove it when done
  • Submodules in the sidebar: open, initialize or update

Built-in terminal

  • A real shell in every repository (⌥T), several per repo, with colors, completion, mouse selection and ⌘C

Find and do things faster

  • Command palette (⌘P / ⌘K): any action, branch checkout, tab or repository
  • Search history by message, author or SHA (⌘F), and filter the sidebar
  • Undo and redo (⌘Z / ⌘⇧Z) for commits, resets, rebases, checkouts, branches and tags, without ever overwriting uncommitted work

History editing

  • Interactive rebase: reorder, reword, squash, fixup or drop commits
  • Conflict editor: pick ours, theirs or both per conflict, then mark resolved
  • Select several commits (⌘/Shift-click) to cherry-pick, revert or rebase them together
  • Drag a branch onto another to merge or rebase
  • Hide or solo branches in the graph

Reading code

  • Syntax-highlighted diffs with a side-by-side view
  • File history that follows renames, and blame
  • Commit signature status (GPG and SSH)

Integrations and AI

  • GitHub pull requests in the sidebar when the GitHub CLI (gh) is installed
  • AI commit messages, branch names and stash messages with your own key (OpenAI, Anthropic, Mistral, Gemini, OpenRouter or a local Ollama model)
